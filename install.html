Install it on your device

Pick your device - we've chosen the one you're on. It takes less than a minute.

Android

Chrome, Edge and Samsung Internet can all install SnakeList.

  1. Open snakelist.com in Chrome (or Edge or Samsung Internet).
  2. If an Install bar or button appears, tap it. If not, tap the browser menu .
  3. Choose Install app or Add to Home screen - the name depends on the browser. In Samsung Internet it's Add page to then Home screen.
  4. Confirm with Install (or Add).
  5. Open SnakeList from your home screen or app drawer.

Tip: on this page, the Install SnakeList button at the top opens the install window directly when your browser allows it.

iPhone & iPad

Apple doesn't show an install button on websites - it takes a few taps in the Share menu instead.

  1. Open snakelist.com in Safari. (On iOS and iPadOS 16.4 or newer, Chrome and Edge work too.)
  2. Tap the Share button - at the bottom of the screen on iPhone, at the top on iPad. In Chrome it's at the top right.
  3. Scroll down and tap Add to Home Screen.
  4. Check the name says SnakeList, then tap Add.
  5. Open SnakeList from your Home Screen.

Good to know: on iPhone and iPad the Home Screen app keeps its own storage, separate from Safari - snakes you ticked off in Safari won't appear in it by themselves.

Windows

Use Microsoft Edge or Google Chrome. (Firefox can't install websites as apps.)

  1. Open snakelist.com in Microsoft Edge or Google Chrome.
  2. Look for the install icon at the right end of the address bar, and click it.
  3. No icon? Open the browser menu ⋯ or ⋮: in Edge choose Apps → Install this site as an app; in Chrome choose Cast, save and share → Install page as app.
  4. Click Install to confirm.
  5. Open SnakeList from the Start menu, the taskbar or your desktop.

Tip: the Install SnakeList button at the top of this page opens the same install window, when your browser allows it.

Mac

Safari on macOS Sonoma (14) or newer, or Chrome or Edge on any recent macOS.

  1. Open snakelist.com in Safari, Chrome or Edge.
  2. In Safari: choose File → Add to Dock… (or the Share button → Add to Dock). In Chrome or Edge: click the install icon in the address bar, or use the browser menu as on Windows.
  3. Confirm with Add (Safari) or Install (Chrome and Edge).
  4. Open SnakeList from your Dock or the Applications folder (Launchpad).

Older Mac? Safari before macOS Sonoma has no Add to Dock - use Chrome or Edge, or keep SnakeList as a bookmark.

Questions

Is SnakeList free to install?

Yes. SnakeList is completely free - to use and to install. There are no purchases inside it.

Is SnakeList available on Android?

Yes - install it from Chrome, Edge or Samsung Internet using the Android steps above. A Google Play version is coming; this page will link to it once it's published.

Can I install SnakeList on an iPhone?

Yes, and on iPad too: open snakelist.com in Safari, tap Share, then Add to Home Screen. On iOS and iPadOS 16.4 or newer you can also do it from Chrome or Edge. SnakeList isn't on the App Store.

Can I install SnakeList on Windows or Mac?

Yes. On Windows, use Microsoft Edge or Google Chrome. On a Mac, use Safari (macOS Sonoma or newer: File → Add to Dock) or Chrome or Edge. Firefox doesn't install websites as apps.

Do I need to create an account?

No. Your lists - the snakes you've seen, want to see and follow - are saved on your device. Signing in is optional.

Does SnakeList work without internet?

Partly. Once you've opened SnakeList with a connection, it can open again without one and show the checklist; photos and map data you've already looked at are kept on your device.

Some things always need internet: snake sightings and conservation status (live from iNaturalist), photos you haven't opened before, the translator and signing in.

How do I uninstall SnakeList?
  • Android: press and hold the SnakeList icon, then tap Uninstall (or Remove).
  • iPhone & iPad: press and hold the icon, tap Remove App, then Delete.
  • Windows: open SnakeList, click the ⋯ menu in its title bar and choose Uninstall - or right-click it in the Start menu and choose Uninstall.
  • Mac: Safari apps: drag SnakeList from Applications to the Bin. Chrome or Edge apps: open SnakeList and choose Uninstall from its menu.
Is the installed version different from the website?

It's the same SnakeList, with the same features. It just opens in its own window, without the browser's address bar.

On Android and on computers it shares your lists with SnakeList in that browser. On iPhone and iPad the Home Screen app keeps its own storage, separate from Safari.

Will SnakeList update automatically?

Yes. Whenever you open it with an internet connection it loads the newest version - there's nothing to update by hand.
