Blood Python

Python brongersmai

Blood Python (Python brongersmai) is a non-venomous python of the family Pythonidae, found in Malaysia, Thailand and Vietnam.

Where the name comes from

Python: named after Python, the serpent that Apollo killed at Delphi in Greek myth[1]

brongersmai: named after Leo Brongersma, a Dutch herpetologist

Blood Python: ‘Python’ – after Python, the giant serpent of Greek myth.
